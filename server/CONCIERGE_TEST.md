# 跨境 Pack · Concierge 测试清单

目标：在写 AI 评分卡和自动采集之前，先验证**“带来源的跨境机会证据包”是否真的能帮卖家做决策**。

## 1. 样本

- 10 个 1–3 人跨境卖家 / 小工作室（Amazon FBA、TikTok Shop、独立站均可）。
- 至少有 1 个正在选品或准备上新品。
- 不同品类优先，避免 10 个人都在看同一个红海类目。

## 2. 测试流程（每位 30 分钟）

### 会前：生成证据包

```bash
cd server
python -m app.cli run \
  --direction "Amazon <品类> 细分，低评论高客单的机会" \
  --keywords "<产品词>,<材质/场景词>" \
  --providers agent-reach.reddit,agent-reach.web \
  --pack crossborder \
  --limit 10 \
  --out briefs
```

会前把 `<run_id>.md` 和 `<run_id>.json` 发给对方，或投屏一起看。

### 会中：不要推销，只观察

1. **先让对方判断**：看完这份证据包，你会继续看哪个机会？为什么？
2. **追问决策依据**：你最看重需求、竞争、利润、供应、合规中的哪一项？现在缺哪一项？
3. **追问现状**：上一次选品你花了多久？用了什么工具？最后怎么拍板？错判过一次吗？损失多少？
4. **追问动作**：看完这份材料，你下一步会做什么？（找供应商 / 下样品单 / 投广告 / 什么都不做）
5. **最后再问付费**：如果这份证据包每天/每周自动更新，你愿意付多少？按月还是按次？

## 3. 通过标准

- ≥ 6/10 能说出具体的“手工拼信息 + 判断没把握”的经历。
- ≥ 4/10 看完证据包后产生真实动作（找供应商、下样品单、投小预算广告、约访谈）。
- ≥ 3/10 愿意为“持续更新的跨境机会证据包”付费，价格 ≥ $19/月或 ≥ $99 买断。
- 至少 2 个人主动问“能不能加某个平台/某个品类”。

## 4. 失败信号

- 对方只说“信息挺全”，但不产生任何动作。
- 对方认为公开信号没用，只信平台后台数据。
- 对方只愿意为“选品数据库”付费，不愿意为“判断/证据”付费。
- 10 个人里没有一个人愿意留下联系方式继续试用。

## 5. 测试后要留下的资产

- 10 份带原话引用的访谈记录。
- 3–5 个高频“缺失信息”清单（例如：关税、头程、退货率、认证）。
- 2–3 个真实付费意愿价格点。
- 1 份“卖家原话 → 评分卡维度”的映射表，作为 AI Analyzer 的输入。
